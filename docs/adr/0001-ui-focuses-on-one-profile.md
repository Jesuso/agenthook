# The UI shows one profile at a time

The web UI is one process serving every profile, but it presents them as a Home of per-profile cards and a dashboard scoped to a single profile. There is deliberately no cross-profile ticket table, activity feed, or aggregate totals (cost, needs-you). A person works one area at a time, and merging every profile into one view overwhelms them, which defeats agenthook's purpose of reducing human information load. A cross-profile inbox was considered and rejected.
