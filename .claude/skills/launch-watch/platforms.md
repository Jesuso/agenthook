# Platforms: norms and accounts

What a first-time poster needs to know. When something here may have changed (rules, limits),
check the platform's current guidelines page rather than trusting this file.

## Accounts checklist (the maintainer does these, by hand)

- [ ] **Hacker News** — news.ycombinator.com → "login" → create account. Username + password
      only, no email required (add one in your profile for password resets). New accounts show a
      green username for the first weeks; that's normal. Read the guidelines
      (news.ycombinator.com/newsguidelines.html) and Show HN rules (news.ycombinator.com/showhn.html).
- [ ] **Reddit** — reddit.com → sign up. Many subreddits hide posts from new or low-karma
      accounts; commenting helpfully in subreddits you actually read for a couple of weeks fixes
      that. Before posting anywhere, read that subreddit's sidebar rules (self-promotion limits,
      required flair, "showcase" days).
- [ ] **Claude Code / Anthropic Discord** — join, read the rules channel, find the channel meant
      for sharing projects. Don't post in general/help channels.
- [ ] **GitHub** — already have it. Turn on Discussions for the repo (Settings → Features) so
      questions have a home that isn't the issue tracker.

Use one consistent name across them if you're comfortable with it; it helps people connect the
post to the repo. Turn on email notifications for replies on Reddit and GitHub.

## Hacker News

- **Show HN** is for things people can try now. Title: `Show HN: agenthook – <what it does>`.
  Link the GitHub repo; put the explanation in the text box as a first comment-style body.
- **Never ask anyone to upvote** or share the link asking for votes; HN detects voting rings and
  buries the post. Sharing the link with "I posted this, feedback welcome" is fine.
- Timing: weekday mornings US Pacific are commonly suggested. Be available for the next 3–4
  hours to answer — early, thoughtful replies from the author matter most.
- Tone: technical, modest, specific. Admit limitations openly (security posture, early project).
  Criticism is often blunt; answer the substance once.
- If a Show HN gets no traction, a repost after a while is allowed; don't repost the same day.

## Reddit

- Each subreddit has its own rules; self-promotion is often limited (e.g. a share of your
  activity, or only on specific days/flairs). Read before posting.
- Candidate subreddits for the soft launch: r/ClaudeAI (core users: Claude Code). Others only if
  their rules allow project posts.
- Lead with what problem it solves and a short demo (the GIF), not a feature list. Say you're the
  author. Reply to every genuine question in the first day.

## Discord

- Post once in the projects/showcase channel with a 2–3 line description, the GIF, and the repo
  link. Answer in a thread. Don't DM people unprompted.

## What to have ready before any post

- `/pre-release` green on the version people will install.
- README leads with the quickstart; the GIF loads.
- The post text from `docs/launch/announcement.md`, reviewed by the maintainer.
- 1–2 hours free right after posting.
